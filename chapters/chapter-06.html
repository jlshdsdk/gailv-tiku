本章题目

1. 总体　是指研究对象的某个性能指标的全体，通常用一随机变量 $X$ 代表总体.
2. 个体　是指每一个研究对象.
3. 样本　从总体中抽取 $n$ 个个体，称作来自总体的容量为 $n$ 的样本.
简单随机样本　是指 $n$ 个相互独立，而且与总体 $X$ 同分布的随机变量 $X_1, X_2, \cdots, X_n$，简称随机样本，也常以随机向量 $(X_1, X_2, \cdots, X_n)$ 表示. 它们的一组观察值 $x_1, x_2, \cdots, x_n$ 称为样本值.
4. 统计量　称不含未知参数的样本函数 $g(X_1, X_2, \cdots, X_n)$ 为统计量.
常见统计量　$\bar{X} = \dfrac{1}{n}\sum\limits_{i=1}^{n} X_i$ 为样本均值，

$$S^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2 \text{ 为样本方差，}$$

$$S = \sqrt{S^2} \text{ 称为样本标准差，}$$

$$A_k = \frac{1}{n}\sum_{i=1}^{n} X_i^k \text{ 为 } k \text{ 阶样本原点矩，}$$

$$B_k = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^k \text{ 为 } k \text{ 阶样本中心矩，}$$

其中　$B_2 = S_n^2 = \dfrac{1}{n}\sum\limits_{i=1}^{n}(X_i - \bar{X})^2 = \dfrac{n-1}{n}S^2$.
5. 经验分布函数
从总体 $X$ 中抽取一个容量为 $n$ 的样本，将其观察值 $(x_1, x_2, \cdots, x_n)$ 按大小顺序，重新排列如下

$$x_1^* \le x_2^* \le \cdots \le x_n^*,$$

对于任意的实数 $x$，定义函数

$$F_n(x) = \begin{cases} 0, & x < x_1^* \\ \dfrac{k}{n}, & x_k^* \le x < x_{k+1}^*, \quad k = 1, 2, \cdots, n-1 \\ 1, & x_n^* \le x \end{cases}$$

称 $F_n(x)$ 为总体 $X$ 由 $x_1, x_2, \cdots, x_n$ 所决定的样本分布函数或经验分布函数.
格列汶科定理　当 $n \to \infty$ 时，$F_n(x)$ 依概率 1 关于 $x$ 均匀地收敛于 $F(x)$. 即说明：当 $n$ 很大时，样本分布函数 $F_n(x)$ 近似于总体分布函数 $F(x)$.
6. $\chi^2$ 分布
（1）定义：设随机变量 $X_1, \cdots, X_n$ 相互独立同分布 $N(0,1)$，若有 $\chi^2 = \sum\limits_{i=1}^{n} X_i^2$，则随机变量 $\chi^2$
的分布称为 $n$ 个自由度的 $\chi^2$ 分布. 即 $\chi^2 \sim \chi^2(n)$. 其概率密度函数为

$$\varphi(x) = \begin{cases} \dfrac{1}{2^{\frac{n}{2}}\Gamma(\dfrac{n}{2})} x^{\frac{n}{2}-1} e^{-\frac{x}{2}}, & x > 0 \\ 0, & x \le 0 \end{cases}$$

用图形表示其密度函数为图 6-1.

图6-1：χ² 分布密度函数曲线族。纵轴记为 $y(x,n)$，刻度 0.05、0.10、0.15、0.20；横轴 $x$ 刻度 5、10、15、20、25、30、35、40。四条曲线分别为 $n=1$、$n=4$、$n=10$、$n=20$ 的 χ² 密度曲线：$n=1$ 从纵轴上高处（约0.2以上）单调下降；$n=4$ 峰值约在 $x=2$ 处（约0.18）；$n=10$ 峰值约在 $x=8$ 处（约0.1）；$n=20$ 峰值约在 $x=18$ 处（约0.06），峰随 $n$ 增大右移且变低变宽。

（2）性质：①$E(\chi^2(n)) = n, D(\chi^2(n)) = 2n$.
②设 $X \sim \chi^2(m), Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 相互独立. 则

$$X + Y \sim \chi^2(m+n).$$

（3）上 $\alpha$ 分位点：对于给定的正数 $\alpha (0 < \alpha < 1)$，称满足条件

$$P\{\chi^2 > \chi^2_\alpha(n)\} = \alpha$$

的点 $\chi^2_\alpha(n)$ 为 $\chi^2$ 分布的上 $\alpha$ 分位点.
7. $t$ 分布
（1）定义：设随机变量 $X$ 与 $Y$ 相互独立. $X \sim N(0,1), Y \sim \chi^2(n)$，若 $T = \dfrac{X}{\sqrt{\dfrac{Y}{n}}}$，则随机变量 $T$
的分布称为 $n$ 个自由度的 $t$ 分布，即 $T \sim t(n)$，其概率密度函数为

$$\varphi(x) = \frac{\Gamma(\dfrac{n+1}{2})}{\sqrt{n\pi}\Gamma(\dfrac{n}{2})}\left(1 + \frac{x^2}{n}\right)^{-\frac{n+1}{2}} \quad (-\infty < x < +\infty).$$

用图形表示其概率密度为图 6-2.
（2）性质：①$E(t(n)) = 0, D(t(n)) = \dfrac{n}{n-2} \quad (n > 2)$；
②$\lim\limits_{n \to \infty} \varphi(x) = \dfrac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$，故 $n$ 足够大时，$t$ 分布近似于 $N(0,1)$；
③若 $T \sim t(n)$，则 $T^2 \sim F(1, n)$；
（3）上 $\alpha$ 分位点：$t(n)$ 分布的上 $\alpha$ 分位点 $t_\alpha(n)$ 是指满足

$$P\{T > t_\alpha(n)\} = \alpha \quad (0 < \alpha < 1) \quad \text{的点 } t_\alpha(n).$$

其中　$t_{1-\alpha}(n) = -t_\alpha(n)$.

图6-2：t 分布概率密度曲线族。纵轴记为 $y(x,n)$，刻度 0.1、0.2、0.3、0.4；横轴 $x$ 刻度 $-4,-3,-2,-1,0,1,2,3,4$。三条曲线分别为 $n=1$、$n=5$、$n=\infty$：曲线均关于 $x=0$ 对称、钟形；$n=1$ 峰最低（约0.32）且尾部最厚，$n=5$ 峰居中，$n=\infty$ 峰最高（约0.38，即标准正态）。

8. $F$ 分布
（1）定义：设随机变量 $X$ 与 $Y$ 相互独立，且分别服从 $\chi^2(m)$ 和 $\chi^2(n)$ 分布，若 $F = \dfrac{\dfrac{X}{m}}{\dfrac{Y}{n}}$，则 $F$ 服从自由度为 $m, n$ 的 $F$ 分布. 即 $F \sim F(m,n)$，其概率密度函数为

$$\varphi(x) = \begin{cases} \dfrac{\Gamma(\dfrac{m+n}{2})}{\Gamma(\dfrac{m}{2})\Gamma(\dfrac{n}{2})} m^{\frac{m}{2}} n^{\frac{n}{2}} \dfrac{x^{\frac{m}{2}-1}}{(mx+n)^{\frac{m+n}{2}}}, & x > 0 \\ 0, & x \le 0 \end{cases}$$

用图形表示其概率密度函数为图 6-3.

图6-3：F 分布概率密度曲线族。纵轴记为 $\varphi(x)$，横轴为 $x$（无具体刻度）。三条曲线分别为 $n_1=20, n_2=100$（峰最高最靠左）、$n_1=20, n_2=25$（峰居中）、$n_1=20, n_2=10$（峰最低且右移、尾部最厚），曲线均从原点起先升后降、右偏。

（2）性质：①若 $X \sim F(m,n)$，则

$$E(X) = \frac{n}{n-2} \quad (n > 2),$$

$$D(X) = \frac{n^2(2m+2n-4)}{m(n-2)^2(n-4)} \quad (n > 4);$$

②若 $X \sim F(m,n)$，则 $\dfrac{1}{X} \sim F(n,m)$；
（3）上 $\alpha$ 分位点：满足 $P\{F > F_\alpha(m,n)\} = \alpha \quad (0 < \alpha < 1)$ 的点 $F_\alpha(m,n)$ 称为上 $\alpha$ 分位点，且 $F_{1-\alpha}(m,n) = \dfrac{1}{F_\alpha(n,m)}$.
9. 正态总体的常用结论
（1）若总体 $X$ 服从正态分布 $N(\mu, \sigma^2)$，$X_1, \cdots, X_n$ 是其样本，$\bar{X}$ 和 $S^2$ 分别为样本均值和方差，则
①$\bar{X} \sim N(\mu, \dfrac{\sigma^2}{n})$ 或 $\dfrac{\bar{X} - \mu}{\sigma}\sqrt{n} \sim N(0,1)$；
②$\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$；
③$\dfrac{\bar{X} - \mu}{S}\sqrt{n} \sim t(n-1)$；
④$\bar{X}$ 与 $S^2$ 相互独立.
（2）若 $X_1, X_2, \cdots, X_n$ 和 $Y_1, Y_2, \cdots, Y_m$ 分别表示取自两个正态总体 $N(\mu_1, \sigma_1^2)$ 和 $N(\mu_2, \sigma_2^2)$ 的简单随机样本，$\bar{X}, \bar{Y}$ 和 $S_1^2, S_2^2$ 分别表示其样本均值和方差，则有
①$\dfrac{\dfrac{S_1^2}{\sigma_1^2}}{\dfrac{S_2^2}{\sigma_2^2}} \sim F(n-1, m-1)$；
②$\sqrt{\dfrac{mn(n+m-2)}{n+m}} \dfrac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{(n-1)S_1^2 + (m-1)S_2^2}} \sim t(n+m-2)$. （当 $\sigma_1^2 = \sigma_2^2$ 时）

分析　利用正态分布的性质和 $\chi^2$ 分布的表达式判断.

最终答案：

故答案为(C).

$$Y = \frac{X_1^2 + \cdots + X_{10}^2}{2(X_{11}^2 + \cdots + X_{15}^2)}$$

服从______分布，参数为______.

故 $Y$ 服从 $F$ 分布，参数为 $(10,5)$.

【1.3】

设 $X_1, X_2, \cdots, X_9$ 是总体 $X$ 的一个简单随机样本，$X$ 服从正态分布 $N(\mu, \sigma^2)$，$Y_1 = \dfrac{1}{6}(X_1 + X_2 + \cdots + X_6)$，$Y_2 = \dfrac{1}{3}(X_7 + X_8 + X_9)$，$S^2 = \dfrac{1}{2}\sum\limits_{i=7}^{9}(X_i - Y_2)^2$，$T = \dfrac{\sqrt{2}(Y_1 - Y_2)}{S}$.
证明 $T \sim t(2)$.

【解析】

证　因为 $X \sim N(\mu, \sigma^2)$，$X_i \sim N(\mu, \sigma^2)$，所以 $Y_1 \sim N(\mu, \dfrac{\sigma^2}{6})$，$Y_2 \sim N(\mu, \dfrac{\sigma^2}{3})$，
故 $Y_1 - Y_2 \sim N(0, \dfrac{\sigma^2}{2})$，因此有

$$\frac{Y_1 - Y_2}{\dfrac{\sigma}{\sqrt{2}}} = \frac{\sqrt{2}(Y_1 - Y_2)}{\sigma} \sim N(0,1).$$

又由于

$$S^2 = \frac{1}{2}\sum_{i=7}^{9}(X_i - Y_2)^2 = \frac{1}{3-1}\sum_{i=7}^{9}(X_i - Y_2)^2,$$

而

$$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1),$$

所以 $\dfrac{2S^2}{\sigma^2} \sim \chi^2(2)$.
因为 $Y_2$ 和 $S^2$ 相互独立，而且 $Y_1$ 与 $Y_2$，$Y_1$ 与 $S^2$ 也相互独立，所以 $Y_1 - Y_2$ 与 $S^2$ 相互独立.
则有 $\dfrac{\sqrt{2}(Y_1 - Y_2)}{\sigma}$ 与 $\dfrac{2S^2}{\sigma^2}$ 相互独立.
那么

$$T = \frac{\sqrt{2}(Y_1 - Y_2)}{S} = \frac{\dfrac{\sqrt{2}(Y_1 - Y_2)}{\sigma}}{\sqrt{\dfrac{2S^2}{2\sigma^2}}} \sim t(2),$$

故 $T$ 服从自由度为 2 的 $t$ 分布.

【1.4】

设 $X \sim N(a,2)$，$Y \sim N(b,2)$ 且 $X, Y$ 独立，分别在 $X$、$Y$ 中取容量为 $m$ 和 $n$ 的简单随机样本，样本方差分别记为 $S_X^2$ 和 $S_Y^2$，则 $T = \dfrac{1}{2}[(m-1)S_X^2 + (n-1)S_Y^2]$ 服从（　　）分布.
（A）$t(m+n-2)$　　　　（B）$F(m-1, n-1)$
（C）$\chi^2(m+n-2)$　　　　（D）$t(m+n)$

【解析】

解　因为

$$\frac{(m-1)S_X^2}{2} \sim \chi^2(m-1), \qquad \frac{(n-1)S_Y^2}{2} \sim \chi^2(n-1).$$

所以　$T \sim \chi^2(m+n-2)$.

最终答案：

故应选(C).

【1.5】

设随机变量 $X \sim t(n)$ $(n > 1)$，$Y = \dfrac{1}{X^2}$，则（　　）.
（A）$Y \sim \chi^2(n)$　　　　（B）$Y \sim \chi^2(n-1)$
（C）$Y \sim F(n,1)$　　　　（D）$Y \sim F(1,n)$

【解析】

解法一　利用 $t$ 分布和 $F$ 分布的性质求解.
因为 $X \sim t(n)$，由 $t$ 分布性质可得 $X^2 \sim F(1,n)$.
又根据 $F$ 分布的性质

$$\frac{1}{X^2} \sim F(n,1),$$

最终答案：

故 $Y = \dfrac{1}{X^2} \sim F(n,1)$ 分布，答案为(C).
解法二　利用 $t$ 分布和 $F$ 分布的定义求解.
因 $X \sim t(n)$，所以 $X$ 具有如下结构：

$$X = \frac{U}{\sqrt{\dfrac{V}{n}}},$$

其中 $U \sim N(0,1)$，$V \sim \chi^2(n)$，且 $U$ 与 $V$ 相互独立. 从而

$$X^2 = \frac{U^2}{\dfrac{V}{n}} \quad \text{即} \quad \frac{1}{X^2} = \frac{\dfrac{V}{n}}{U^2}.$$

$U^2 \sim \chi^2(1)$，且 $U^2$ 与 $V$ 也相互独立，由定义

$$\frac{1}{X^2} = \frac{\dfrac{V}{n}}{\dfrac{U^2}{1}} \sim F(n,1).$$

【1.6】

设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X \sim N(\mu, \sigma^2)$ 的一个样本，样本均值和方差分别为 $\bar{X}$ 和 $S^2$，$X_{n+1}$ 为对 $X$ 的又一独立观测值，求统计量 $Y = \dfrac{X_{n+1} - \bar{X}}{S}\sqrt{\dfrac{n}{n+1}}$ 的分布.

【解析】

解　因为 $\bar{X} \sim N(\mu, \dfrac{\sigma^2}{n})$，$X_{n+1} \sim N(\mu, \sigma^2)$ 且两者独立.
所以

$$X_{n+1} - \bar{X} \sim N(0, \frac{n+1}{n}\sigma^2),$$

$$U = \frac{X_{n+1} - \bar{X}}{\sqrt{\dfrac{n+1}{n}}\sigma} \sim N(0,1),$$

而 $\chi^2 = \dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ 且与 $U$ 独立，则由 $t$ 分布定义可知，

$$\frac{U}{\sqrt{\dfrac{\chi^2}{n-1}}} = \sqrt{\frac{n}{n+1}} \cdot \frac{X_{n+1} - \bar{X}}{S} \sim t(n-1).$$

题型2 利用抽样分布确定参数
【1.7】

设 $X_1, X_2, X_3, X_4$ 是来自正态总体 $N(0,2^2)$ 的简单随机样本，

$$X = a(X_1 - 2X_2)^2 + b(3X_3 - 4X_4)^2,$$

则当 $a =$ ______，$b =$ ______ 时，统计量 $X$ 服从 $\chi^2$ 分布，其自由度为______.

【解析】

解　令　$Y_1 = X_1 - 2X_2$，则　$\dfrac{Y_1}{\sqrt{20}} \sim N(0,1)$，
所以 $a = \dfrac{1}{20}$ 时，$\sqrt{a}(X_1 - 2X_2) \sim N(0,1)$.
同样令　$Y_2 = 3X_3 - 4X_4$，则　$\dfrac{Y_2}{10} \sim N(0,1)$，
所以 $b = \dfrac{1}{100}$ 时，$\sqrt{b}(3X_3 - 4X_4) \sim N(0,1)$，　此时 $X = \dfrac{Y_1^2}{20} + \dfrac{Y_2^2}{100} \sim \chi^2(2)$.

最终答案：

故应填 $\dfrac{1}{20}, \dfrac{1}{100}, 2$.

【1.8】

设 $X_1, X_2, \cdots, X_5$ 是取自正态分布 $N(0, \sigma^2)$ 的一个简单随机样本，若 $\dfrac{a(X_1 + X_2)}{\sqrt{X_3^2 + X_4^2 + X_5^2}}$ 服从 $t$ 分布，则 $a =$ ______.

【解析】

解　因为

$$\frac{X_1 + X_2}{\sqrt{2}\sigma} \sim N(0,1), \qquad \frac{1}{\sigma^2}(X_3^2 + X_4^2 + X_5^2) \sim \chi^2(3)$$

且 $\dfrac{X_1 + X_2}{\sqrt{2}\sigma}$ 与 $\dfrac{1}{\sigma^2}(X_3^2 + X_4^2 + X_5^2)$ 独立，于是

$$\frac{\dfrac{X_1 + X_2}{\sqrt{2}\sigma}}{\sqrt{\dfrac{\dfrac{1}{\sigma^2}(X_3^2 + X_4^2 + X_5^2)}{3}}} = \frac{\sqrt{\dfrac{3}{2}}(X_1 + X_2)}{\sqrt{X_3^2 + X_4^2 + X_5^2}} \sim t(3) \Rightarrow a = \sqrt{\frac{3}{2}}.$$

题型3 利用抽样分布求概率
【1.9】

在总体 $N(12,4)$ 中随机抽一容量为 5 的样本 $X_1, X_2, X_3, X_4, X_5$.
（1）求样本均值与总体均值之差的绝对值大于 1 的概率.
（2）求概率 $P\{\max(X_1, X_2, X_3, X_4, X_5) > 15\}$.
（3）求概率 $P\{\min(X_1, X_2, X_3, X_4, X_5) < 10\}$.

【解析】

解　（1）因 $\bar{X} \sim N(12, \dfrac{4}{5})$，所以

$$P\{|\bar{X} - 12| > 1\} = P\left\{\left|\dfrac{\bar{X} - 12}{\sqrt{\dfrac{4}{5}}}\right| > \dfrac{\sqrt{5}}{2}\right\}$$

$$= 2 - 2\Phi(\frac{\sqrt{5}}{2}) = 2 \times [1 - \Phi(1.12)] = 2 \times (1 - 0.8686) = 0.2628.$$

（2）$P\{\max(X_1, X_2, X_3, X_4, X_5) > 15\}$
$= 1 - P\{X_1 \le 15, X_2 \le 15, X_3 \le 15, X_4 \le 15, X_5 \le 15\}$
$= 1 - \prod\limits_{i=1}^{5} P\{X_i \le 15\} = 1 - \prod\limits_{i=1}^{5} P\left\{\dfrac{X_i - 12}{2} \le \dfrac{15 - 12}{2}\right\}$
$= 1 - [\Phi(1.5)]^5 = 1 - (0.9332)^5 = 0.2923.$

$$S^2=\frac{1}{n-1}(\sum_{i=1}^{n}X_i^2-n\bar{X}^2),$$

问题就变得简单了.

【解析】

解 (1)$X_1,X_2,\cdots,X_n$ 相互独立且与 $X$ 有相同的分布,所以

$$E(X_i)=E(X),$$

$$E(\bar{X})=E\left(\frac{1}{n}\sum_{i=1}^{n}X_i\right)=\frac{1}{n}\sum_{i=1}^{n}E(X_i)=\frac{1}{n}nE(X)=E(X).$$

$$D(X_i)=D(X)\quad(i=1,2,\cdots,n),$$

$$D(\bar{X})=D\left(\frac{1}{n}\sum_{i=1}^{n}X_i\right)=\frac{1}{n^2}\sum_{i=1}^{n}D(X_i)=\frac{1}{n^2}nD(X)=\frac{1}{n}D(X).$$

故 $D(\bar{X})=\frac{\sigma^2}{n}$.
(2)$E(S^2)=E\left[\frac{1}{n-1}(\sum_{i=1}^{n}X_i^2-n\bar{X}^2)\right]=\frac{1}{n-1}\left[\sum_{i=1}^{n}E(X_i^2)-nE(\bar{X}^2)\right].$
因为

$$E(X_i^2)=D(X_i)+[E(X_i)]^2\quad(i=1,2,\cdots,n),$$

$$E(\bar{X}^2)=D(\bar{X})+[E(\bar{X})]^2,$$

因此

$$E(X_i^2)=D(X)+[E(X)]^2\quad(i=1,2,\cdots,n),$$

$$E(\bar{X}^2)=\frac{1}{n}D(X)+[E(X)]^2,$$

故

$$E(S^2)=\frac{1}{n-1}\{nD(X)+n[E(X)]^2-D(X)-n[E(X)]^2\}=D(X),$$

最终答案：

所以 $E(S^2)=\sigma^2$.
